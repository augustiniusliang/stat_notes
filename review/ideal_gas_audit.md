# 量子理想气体数学审查

基线：`65f73ff5b9fb07ff9b339a63072a32808d78a4cd`，默认分支 master。
范围：`chaps/ideal_gas.tex` 全章；保留章节层级、中文叙述及 linenomath 排版。

## 确定错误

| 原式或步骤 | 修正及影响 |
| --- | --- |
| 首式同时含外部 h^-3 与 D(p,q)=h^-3 | 只保留 D 内的因子；原式重复计数且量纲错误 |
| D(ε) 的系数 4π(2m)^(3/2) | 应为 2π(2m)^(3/2)，因为 p²dp=(2m)^(3/2)√ε dε/2；修正所有相应积分 |
| Zeta 表达式中遗漏温度因子 | N 补 β^-3/2；Ω、U、p 补 β^-5/2；原来的热波长最终式正确 |
| 零温 μ=(6π²n/d)^(2/3)/(2m) | 补 ℏ²；原式量纲错误，其后的 εF=ℏ²kF²/(2m) 正确 |
| 零温 U 的动量积分缺少态数权重 | 补 d/h³；最终 3NεF/5 正确 |
| 低温 D(ε)=2N√ε/(3εF^(3/2)) | 应为 3N√ε/(2εF^(3/2))，积分到 εF 才等于 N |
| δμ 中间系数 π²/6 | 解线性粒子数方程得到 π²/9；原来的最终 -π²(kBT)²/(12εF) 正确 |
| 有限温度 p=-(∂U/∂V)_N | 必须固定熵，或对自由能固定温度求导；改用 p=2U/(3V)，保留正确的最终压强 |
| Sommerfeld 首积分使用 εF，后续使用 μ | 统一为 μ(T)，固定 N 时需随后求解 μ(T) |
| Laplace 中换元混用变量、漏平移因子，且将无穷展开当恒等式 | 用实积分分离粒子和空穴，推导有限阶渐近式；保留正确系数 |
| “先研究简并气体”和 N→∞ 的简并定义 | 前者改非简并，后者改 T≪TF；与热力学极限分开 |

## 记号歧义

- 保留 g=+1（Fermi）、-1（Bose）；内部简并度另记 d=2s+1。第一节仍按 d=1 推导，明确一般化规则。
- D(p,q) 统一表示每相空间体积的态密度，而非仅自旋态数；后两节显式式子保持等价。
- ⟨n(p)⟩ 含 d 时是同一动量对内部态求和；单个自旋态的占据数仍不超过 1。
- 未定义的 μF 改为已定义的 εF；将“经典色散关系”说明为非相对论色散关系。

## 仅需补充说明、保留的结果

- λ=h/√(2πmkBT)=√(2πℏ²/(mkBT)) 正确。
- I_g=Γ(s)β^-s ζ_g 正确，增加收敛域。z>1 的 Fermi 情形须由积分定义延拓，不能使用 fugacity 幂级数。
- 原有 μ、U、p 的高温首个交换修正正确；补充反演到 x² 的结果，x=nλ³/d。
- 原有零温 U、p 和低温 μ、U、CV、p 的主要最终系数正确。
- 连续态密度是热力学极限的体积项；Bose 凝聚时应另计 N0。补充零能基态的巨配分函数及占据数。
- p=2U/(3V) 依赖三维、非相对论二次色散；并非任意理想气体都适用。
